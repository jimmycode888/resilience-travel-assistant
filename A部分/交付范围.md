# A 核心与扩展范围

## A 核心

| 内容 | 文件 |
|---|---|
| 共享契约 | `app/src/lib/types/` |
| Journey 解析、分段、跨境归属与几何 | `app/src/lib/route/parse.ts`、`types/journey.ts` |
| 路线供应商接口、离线模板、OSRM 与缓存回退 | `app/src/lib/route/` |
| 地点、口岸、距离基础 | `app/src/lib/geo/`（定位模块为前端基础扩展） |
| 五因子风险与模式权重 | `app/src/lib/risk/` |
| 可靠性、定性信心与四模式排序 | `app/src/lib/reliability/` |
| 团队组合入口、数据作用域／过期检查、硬约束保护 | `app/src/lib/integration/` |
| 独立行程 API、错误处理、契约与测试 | `app/src/lib/api/journey-handler.ts`、`app/src/app/api/journey/`、`app/src/test/` |

## 一并保留的扩展

`JourneyPlanner`、`JourneyMap`、`/journey`、`journey/analysis.ts`：地图选点、搜索、定位、风险图层、演示人流、出发时点比较、Plan B、确定性解释、情景回放与 API 失败后的本机演示回退。

这些是可运行参考实现，便于 C/D/E 接手替换；没有将它们算作其他成员已完成的正式模块。
原有第一阶段应用、适配器和文档也一并保留作为完整运行基线。

## 团队未完成项

正式跨境实时数据／班次、坐标逐项官方核实、C 正式客流／出发窗口／Plan B 模型、LLM 解释、E 正式设计规范及真人验收仍由对应成员继续完成。
到达信心是定性分级，不能解释成百分比。口岸开放时间不代表一定有交通接驳。
