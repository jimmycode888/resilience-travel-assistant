# 韌性出行助手 · 第二階段

目前工作目錄為 `第二阶段信息/`。2026-10-10 已接通離線跨境演示：地圖選點 → 路線風險比較 → 出發時點 → Plan B → 規則解釋與情景回放。

## 啟動

```sh
npm ci
npm run dev -- --port 3100
```

開啟 http://localhost:3100/journey ，按「中環 → 福田」查看三條跨境方案。
`/` 是第一階段通勤入口，`/api/journey` 是第二階段獨立 API。

- `npm run verify`：lint、型別檢查、單元／集成測試、production build。
- `npm run probe:route`：原有路徑讀取探針。
- `npm run probe:risk`：原有風險與排序探針。
- `npm run smoke`：第一階段回歸驗收。

無需密鑰或資料庫。地圖底圖需要網絡；路線、估算與本機回退可離線運行（已載入頁面，尚非 PWA）。

### 自由輸入及公開公交規劃（/journey）

行程頁預設使用公開交通規劃，也可切換原有固定演示。地址搜尋並行查詢香港政府 ALS、Photon / OpenStreetMap，以及已啟用時的高德深圳 POI；選取候選後保留 WGS84 座標。鍵盤方向鍵、Enter、Escape 及交換起終點均可用。

香港段使用 `data/transit/hk-network.json.gz` 官方 GTFS 快照：9,466 個站點、2,452 條可用線路（排除舊皇崗 XB 資料）。依服務日曆、假日例外、跨午夜班次及最多四次乘車搜尋。班次是靜態參考；頻率班次保守預留完整發車間隔，中途站時間按官方時間錨點與站間距離插值，並非即時 ETA。步行候選只供搜尋；最終接駁須由專用 OSM foot profile 核驗，失敗會換候選或回報不可用。

跨境服務組合深圳灣、香園圍／蓮塘兩個道路口岸的兩側行程，依抵達及預留通關完成時刻檢查開放時間，再以完成後時間查詢另一側。通道預留15分鐘及排隊45分鐘明確展示，後者僅是保守假設，不是即時人流。舊皇崗資料不使用，羅湖及落馬洲鐵路口岸暫未覆蓋；本資料集不含港鐵重鐵。

深圳段使用高德官方公交/地鐵接口（2026-10-17已完成真實Key驗證），必須在 `.env.local` 配置 `AMAP_WEB_SERVICE_KEY`，不得使用 `NEXT_PUBLIC_` 前綴。此 Key 只在服務端讀取，請勿提交進版控。配置後重新啟動服務並執行 `npm run probe:transit`，才能確認實際權限及覆蓋，配置存在並不等於驗證成功。GCJ-02 與 WGS84 座標轉換已有回歸測試。口岸入境、出境接駁點已依高德POI分別校正；平台返回步行點與所選地址相距150米以上時，額外查驗步行接駁並計入耗時，不能核驗則不返回完整方案。公開模式啟動時使用當前香港日期時間，不再固定在演示日期。

沒有可確認的深圳段時僅展示已確認香港段，不提供完整路線、出發推薦或虛構接駁。公開模式無網絡時不會自動降級成 fixture。天氣、客流及風險規則仍非實時，界面與來源區明確標示。

維護命令：`npm run transit:import` 由官方 GTFS ZIP 建立帶 SHA256、版本日期的壓縮快照；刷新來源時執行 `npm run transit:import -- --refresh`，並重新啟動服務以載入新快照。`npm run probe:transit` 生成 `docs/transit/coverage.json`。`GET /api/transit-status` 提供資料及配置狀態，不包含密鑰。正式高併發部署應以 `FOOT_ROUTER_URL` 指向自建步行服務；公開 FOSSGIS 預設限速每秒一次並快取成功路段。

詳細驗證範圍與未完成項見 [公交接入與覆蓋報告](docs/transit/TRANSIT_COVERAGE.md)。`/journey-team` 仍是獨立團隊契約測試頁。
