## 啟動與演示

```sh
cd 第二阶段信息
npm ci
npm run dev -- --port 3100
```

打開 http://localhost:3100/journey 。首頁 `/` 保留第一階段入口，並新增第二階段連結。

1. 按「中環 → 福田」，比較三條路線，點路線卡片或地圖路段查看詳情。
2. 試四個偏好；模式同時影響風險權重與排序。相似候選不保證每個模式都產生不同冠軍。
3. 切「東鐵線中斷」後重新比較：東鐵候選不可行，推薦深圳灣巴士方案。
4. 切「黑色暴雨」後重新比較：暫緩，無主推薦／出發時點／Plan B。
5. 拖回放滑桿：08:00 正常、08:20 黑雨、08:40 東鐵中斷。日期固定為演示日。
6. 把出發改為 23:00：關閉的口岸不會成為主推薦或備選。
7. 搜尋中文／英文地點，或點地圖標記。空白處僅吸附到 2 公里內已收錄地點，明示距離。未覆蓋走廊回傳 unavailable。
8. 拒絕定位仍能搜尋；定位成功會顯示藍點與精度圈。附近無已收錄地點不會默默更改起點。
9. 阻斷 `/api/journey` 後再比較：相同驗證與規則在瀏覽器本機計算，明示回退。首次開頁仍需本地伺服器；尚無 PWA 離線安裝能力。

## 模組與 API

- `src/lib/journey/analysis.ts`：候選解析 → 時段人流假設 → 五因子風險 → 硬約束排除 → 四模式排序 → 通關排隊 ETA → 13 個出發時點 → Plan B → 可追溯規則解釋。
- `src/lib/types/journey-analysis.ts`：第二階段獨立、可增量維護的請求與回應契約。
- `src/lib/api/journey-handler.ts` / `POST /api/journey`：strict Zod 驗證；不改第一階段 `/api/decision` 的固定走廊契約。
- `JourneyPlanner` / `JourneyMap`：輸入、地圖、圖層、卡片、逐段詳情、來源、情景回放、導航跳轉。
- Leaflet 延遲載入；CSS 由根 layout 統一載入，避免動態元件樣式未就緒造成圖層位置錯誤。

請求示例：

```json
{
  "origin": "central-exchange-square",
  "destination": "futian-station-sz",
  "departAt": "2026-10-13T08:00:00+08:00",
  "arriveBy": "2026-10-13T11:00:00+08:00",
  "mode": "balanced",
  "scenario": "normal"
}
```

模式：`balanced / fastest / reliable / less_crowded`。情景：`normal / heavy_rain / disruption`。
地點需命中註冊表；時間支援 datetime-local（固定香港時區）及帶偏移量的 ISO。

HTTP 400：不合法 JSON、未知欄位／地點／模式、無效時間、同一地點、到達早於出發。
HTTP 200：正常分析，或合法但未覆蓋／無可行候選的 `action: unavailable`。
HTTP 405：GET。HTTP 500：內部錯誤，前端顯示可重試訊息。
回應不快取；`quality` 固定 fixture，絕不冒充 live。

## 修復與邊界

- 修復 fixture 忽略查詢出發時間、改選終點仍終止於福田的問題。非模板端點使用明示估算步行接駁，不能當真實路網。
- 移除深圳灣路線的「24 小時」錯誤名稱。正常旅客時間參考入境處與海關公開表：06:30–24:00；貨運時間不能套用到旅客。
- 香園圍參考正常開放時間改為 07:00–22:00。六口岸座標仍維持 `coordinatesVerified: false`，不聲稱已核實座標。
- 口岸檢查按通關段的抵達與完成時間（含排隊上限），而非整段旅程出發時間。
- Plan B 排除相同口岸及相同主要長途線路，避免以同受東鐵中斷影響的羅湖方案當作東鐵中斷退路。若無獨立可行備選，回傳 null。
- ETA 在原有風險緩衝外再加入通關排隊上下界；到達期限按保守 ETA 判斷。趕不上期限會明示，不承諾準時。
- 人流只用可檢視的時段假設；解釋由確定性模板產生，沒有呼叫 LLM，沒有編造歷史訓練資料。
- 出發比較不假設暴雨消散或中斷恢復；bestDeparture 是 10 分鐘粒度的單一時點，未宣稱連續最佳窗口。
- Google Maps 只預填起終點並重新規劃，可能不經所選口岸；頁面明示此限制。
- 地圖使用 OSM 標準瓦片，顯示 attribution，不預取／下載離線瓦片；瓦片失敗仍保留本地路線與標記。
