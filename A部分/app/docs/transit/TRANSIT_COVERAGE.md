## 已知覆蓋邊界

- 本香港GTFS不含港鐵重鐵；道路跨境只組合深圳灣、香園圍／蓮塘。羅湖、落馬洲、皇崗等不能計為已覆蓋。
- 端點900米內選取最多12個站點；最多四次乘車（三次換乘）；搜尋接駁最多180米，最終步行路網不超過1.8公里。偏遠地點、出入口阻隔或服務停止時可能無方案。
- 香港公交幾何連接站點，不是道路導航折線；通關通道步行15分鐘、排隊45分鐘為規劃預留，非現場排隊資料。
- 首次瀏覽器查詢曾遇到超時，隨後基準及下午時段複查成功；仍依賴外部步行與公交服務，不能承諾每次低延遲。香港及深圳均不承諾即時車輛到站。香港班次資料需定期重新匯入；改道、停駛仍需查營運商。
- 口岸深圳側入境、出境點分別依2026-10-17高德POI轉成WGS84：深圳灣 B0FFG9KBI4/B0FFHODP60，蓮塘 B0K1DZFFXD/B0KG37PESD。POI代表點不是現場測量的旅檢通道，不能以直線導航。
- 地址搜尋、香港段可用、深圳段可用、完整跨境成功是不同指標，不能混用。

## 配置與持續驗收

1. 在 `A部分/app/.env.local` 保存 `AMAP_WEB_SERVICE_KEY=<Web服務Key>`，不在聊天、前端或版控暴露。
2. 重新啟動服務，檢查 `/api/transit-status`。`configured=true`只代表讀到配置，不代表權限或覆蓋驗證成功。
3. 執行 `npm run probe:transit`，依次重跑香港基準與深圳八區雙向跨境實測，保留失敗原因。命令使用Node的服務端env-file載入配置，避免測試模式忽略`.env.local`。
4. 每區仍需擴大到多個住宅門牌／商場／醫院／校園及平峰、晚間、末班樣本；不能把每區一個POI成功等同該區全部覆蓋。
