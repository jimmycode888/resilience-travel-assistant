# QA 檢查清單

> 負責人：成員 D（前端與 QA）。骨架由成員 A 建立，列出**已實作的狀態**與**待補的檢查項**。
> 問題分級：**P0** 無法打開／無法提交／白屏／核心結果缺失／演示無法繼續；
> **P1** 結果錯誤／主要按鈕不可用／手機嚴重錯位／Plan B 或切換條件無法理解；
> **P2** 輕微樣式、間距、文案問題。

環境：`npm run build && npm run start`（用生產建置測，不要只測 dev）。
