## 4. 降级状态（`MAP-LAYERS-SPEC-v2.md §F`）

### 4.1 地图本身

- [ ] 地图加载中显示 `正在載入地圖…`（`journey-map-skeleton`），**不是空白**
- [ ] 底图瓦片失败显示 `底圖暫時無法載入；參考路線與選點仍可使用。`，**地图容器保留、折线仍画**
- [ ] 无路线数据时地图**不清空**（仍显示已收录地点与口岸）

### 4.2 定位（4 条文案逐字核对）

- [ ] 权限被拒绝：`定位權限被拒絕，請在系統設定中允許定位，或自行選擇起點。`
- [ ] 无法取得位置：`無法取得位置（此裝置可能沒有定位來源），請自行選擇起點。`
- [ ] 逾时：`定位逾時，請再試一次，或自行選擇起點。`
- [ ] 装置不支持：`此裝置不支援定位，請自行選擇起點。`
- [ ] 定位成功但附近无收录点：`已顯示目前位置；附近未有收錄地點，請自行搜尋起點。`

### 4.3 分析与网络

- [ ] 尚无分析结果：`先選一段旅程。`
- [ ] 分析中：`正在重新比較；下方保留上一次結果。`
- [ ] 选项已改未重算：`選項已更改。按「比較行程」更新結果；下方仍是上次分析。`
- [ ] 网络/服务器不可用：`伺服器或網絡不可用，已在本機使用相同演示規則計算。`，且**仍显示三条候选**
- [ ] 分析失败：`role="alert"` 红框提示，非白屏

### 4.4 路线与整体

- [ ] 不可行路线：卡片 tag `不可行` + `exclusions` 逐条红字 + 地图灰虚线
- [ ] 口岸关闭：文案形如 `XXX在預計通關時段未開放（按參考時間表）。`
- [ ] 缺口岸：`缺少可核對的口岸，不能確認可行性。`
- [ ] 无离线走廊：`這組地點尚未有離線走廊，請使用「中環 → 福田」或「坑口 → 中環」示範。`
- [ ] 超过到达期限：`保守 ETA 超過到達期限`
- [ ] 整体 `hold`：标题 `暫緩非必要行程`，且**无「當前推薦」卡片**
- [ ] 整体 `unavailable`：标题 `暫無可行方案`

### 4.5 三者不得混淆（关键）

- [ ] `unavailable`（不可行）≠ `low risk`（低风险）≠ `confidence low`（低可信度）
- [ ] 数据缺失**未被渲染成零风险**（缺失因子须标注，见下）

### 4.6 数据缺口须可见（P1 缺口）

- [ ] `RiskFactor.notices` 有内容时**会在 UI 显示**（现况未显示）
  - 例如 `缺少天氣資料，已按保守假設處理。`、`未接入人流模型，以服務擁擠度代替。`、`缺少服務狀態資料，已按保守假設處理。`
- [ ] `RouteRisk.notices` / `資料品質為 fixture，風險評估可信度已下調。` 可见
- [ ] `RiskBreakdown.confidence` 在风险卡可见
- [ ] 单条路线的 `CandidateRoute.quality`（`live`/`cached`/`fixture`）在路线卡可见
