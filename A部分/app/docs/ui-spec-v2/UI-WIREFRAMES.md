### 2.1 地图专项规则（对应任务书 7 问）

| 问题 | 规范 |
|---|---|
| **推荐路线如何突出** | **线宽 7 + 透明度 1.0**（唯一用宽度表达"推荐"）+ 卡片 tag `當前推薦`。**不用特殊颜色**（避免与风险色冲突） |
| **普通候选如何区分** | 同风险色系，但 **线宽 4 / 透明度 0.5**；卡片 tag `比較方案` |
| **路线选中后如何反馈** | 折线加粗到 7、透明度 1.0（`[現]` 已实作）；卡片 `.is-selected` 边框；**详情区切换到该路线** |
| **风险图层如何阅读** | 颜色 = 风险等级（`--risk-*`）；图例用 **符号 + 文字 + 色块**；关闭「風險上色」后统一 `#2577a4` 中性色 |
| **跨境通关段如何辨识** | 紫 `#8653ad` + **虚线 `7 7`**（**不看颜色也能辨识**）；路段列额外显示 `· 通關段` 文字 |
| **口岸点击后显示什么** | popup：`{口岸名} · 參考開放時間 06:30–22:30 · 座標未核實`（`[現]` 已实作，**保留诚实声明**） |
| **无法绘制路线时保留什么** | 底图瓦片失败 → 保留**折线、起终点、口岸、目前位置**，仅 caption 说明；无路线 → 仍画**已收录地点与口岸**（不清空） |

### 2.2 E 提案 `[改]`

1. **不可行线型** `7 7` → **`2 5`**（现与通关段撞线型）。
2. **白色描边**：折线先画白色底线（`weight+3`）→ 底图可变色仍可辨。
3. **图例**：加符号 `● ▲ ■ ×`、色块；字号 `11px → 12px`。
4. **工具栏 checkbox** `min-height 32px → 44px`。
5. `[缺]` 口岸**选中态**（半径 6→8、`fillOpacity .6→.85`）。

## 8. 7 个页面的状态占位
