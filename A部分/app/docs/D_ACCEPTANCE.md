# D 页面与状态验收

状态：要求已整理，实现和运行验收待完成。

## 输入页

- 预设起点：坑口（富宁花园）、坑口站 A 出口；预设终点：中环（交易广场）、中环（国际金融中心二期）。使用团队定义的 ID。
- 最迟到达时间显示为香港时间；传输用契约规定的 ISO datetime。
- 额外车费为 0–500 整数，换乘上限为 0–5 整数。空输入必须提示，不默认为 0；0 表示不接受额外车费，不是免费出行。
- 正常、暴雨、中断情景清楚标记为演示；live 尝试实时数据但可能回退，不能保证实时。
- 校验失败保留已填值，关联字段错误并移动焦点；提交期间显示反馈，防止无意重复操作。

## 结果页信息顺序

1. 核心摘要：建议出发时间最大；主路线、ETA 范围、信心高/中/低；切换条件简述。360–390px 第一屏检查出发时间与信心，切换条件尽可能靠前。
2. 主路线步骤、Plan B 和完整切换条件。Plan B 不隐藏于折叠区。
3. 理由、提醒、来源、更新时间与限制。数据品质标记在核心摘要也保持可见。

信心是定性判断，不能显示为准时概率。路线、时间、切换条件只展示 API 结果，不由前端重新计算或让大模型编造。

## 状态矩阵

| 状态 | 用户看到什么 | 可执行操作 |
|---|---|---|
| 初始 | 预设行程、输入标签、演示说明 | 修改并提交 |
| 加载 | 正在获取建议；不会残留未标记的旧情景结果 | 等待，重复操作受控 |
| ready | 完整核心摘要、主路线、Plan B | 查看、切换情景 |
| uncertain | 不确定文字、低信心或无 Plan B 原因 | 留意官方信息、调整行程 |
| unavailable | 无可执行建议与原因；不显示空时间/虚构路线 | 返回并调整时间/限制 |
| 输入错误 | 字段或摘要提示，保留输入 | 修正 |
| 接口错误 | 可读错误、重试与返回；不暴露内部堆栈 | 重试/返回 |
| 合法最小回应 | 可选字段缺失仍展示锁定字段 | 正常查看 |
| 上游数据回退 | 仍有结果，说明 cached/fixture 及更新时间 | 查看回退说明 |
| 浏览器断网 | 按 A 确认的离线范围执行；不能把服务端回退当断网可用 | 提示恢复网络/使用已备份版本 |

## 响应式与可访问性

检查 360/390/768/1280px、200% 缩放；无横向溢出。触控目标至少 44px，正文对比度至少 4.5:1。输入有 label，分组有 legend；状态有文字，不只靠颜色。键盘完成输入→提交→情景切换→重试；radio 组支持方向键，焦点可见。加载/结果使用恰当 live 提示，错误使用 alert，避免重复播报。

当前版本 verify 与 smoke 通过；QA 核心项实测有证据；三情景各连续操作五次；P0 清零，P1 修复或明确交给 A；五人测试至少四人在不提示情况下完成核心任务。只完成文档不能标记 D 全部完成。
