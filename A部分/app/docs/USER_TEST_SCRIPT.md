
## 4. 訪談問題（任務後，5 分鐘）

1. 你剛才最先看到的是哪一項資訊？
2. 「到達信心 高」對你來說是什麼意思？
3. 如果早上真的看到這個畫面，你會照著做嗎？為什麼？
4. 哪一項資訊對你最沒用？哪一項你想看得更大／更早看到？
5. 如果主路線延誤但你已經出門了，你希望畫面告訴你什麼？
6. 你會想每天用嗎？什麼情況下會想打開它？
