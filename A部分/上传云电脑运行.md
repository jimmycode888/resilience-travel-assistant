# 上传云电脑与运行

## 1 上传

上传 `A部分_云电脑交付_2026-10-10.zip` 并解压。保持 `A部分/app` 内的目录结构。
本包不包含 `node_modules`、`.next`、个人工具记录或真实 `.env`；无需上传本机依赖。

## 2 环境

使用 Node.js 22 或 24 LTS 及其自带 npm；项目最低版本为 Node 20.11。
支持 Linux、Windows 和 macOS，命令请在 `A部分/app` 内执行。源码不依赖个人电脑的绝对路径。

```sh
node -v
npm -v
npm ci
npm run verify
```

`npm ci` 按 `package-lock.json` 安装。不要把 Mac 的 node_modules 复制到 Linux/Windows。
默认无需 `.env.local`。如需配置已有可选实时适配器，复制 `.env.example` 并阅读注释；这些变量不会把第二阶段演示自动变成跨境实时版本。

## 3 开发运行

```sh
npm run dev -- --hostname 0.0.0.0 --port 3000
```

云电脑浏览器：`http://localhost:3000/journey`。
从自己的电脑访问：使用云平台提供的 3000 端口转发／Web 预览地址，路径追加 `/journey`。
如平台要求映射端口，按其控制台配置。浏览器定位通常需要 HTTPS 或 localhost。

## 4 生产运行

```sh
npm run build
npm run start -- --hostname 0.0.0.0 --port 3000
```

关闭终端可能终止服务。如需持续托管，使用云平台自己的进程管理／部署入口。
同一份代码不要同时运行 dev 和 build，共用 `.next` 会导致资源不一致。

## 5 验收

- `/api/health` 返回正常。
- `/journey` 点击「中环 → 福田」，显示三条候选。
- 东铁中断情景排除铁路方案；黑雨情景暂缓。
- 可查看五因子风险、定性信心、ETA、出发时点与 Plan B。
- 无底图网络时仍能显示参考折线；没有正式实时班次与实测排队。

如要另写前端，可以调用 `POST /api/journey` 获取演示 JSON；正式团队模块按 `其他成员接口.md` 组合。
