# DESIGN-TOKENS — 視覺設計 token（UI Baseline v1.0）

> **全部取自當前 Prototype 實際程式碼**（`src/index.css` 的 `:root` 與實際使用處），
> 只記錄**已經存在並實際使用**的設計系統，未新增任何規範。
>
> 視覺方向：**現代、克制、decision-first 的 SaaS** —— 淺色底、白色圓角卡、柔和藍 accent、充足留白、細邊框、柔和陰影、大圓角、極簡路線示意。

---

## 1. Typography

### 1.1 字級（6 檔，全站僅此 6 個值）

| Token | 值 | 用途 | 使用次數 |
|---|---|---|---|
| `--f-12` | `12px` | 最小字級：標籤、說明、註記、chips、統計標題 | 46 |
| `--f-13` | `13px` | 正文、次要文字、按鈕、統計值 | 35 |
| `--f-15` | `15px` | 欄位輸入、卡片小標、重點行 | 7 |
| `--f-17` | `17px` | 卡片標題、產品名、路線名 | 5 |
| `--f-24` | `24px` | 到達區間、區段大標、狀態卡標題 | 5 |
| `--f-43` | `43px` | **建議出發時間**（全站最大）、輸入頁主標 | 4 |

**正文字最小 12px**，無 7–10px 字級。

### 1.2 字重（3 檔）

| 值 | 用途 |
|---|---|
| `600` | 次要強調：標籤、統計值、次按鈕、chip |
| `700` | 主要強調：標題、CTA、行動徽章、品牌名 |
| `800` | 區段小標（`section-label`）、step number |

### 1.3 行高

| 值 | 用途 |
|---|---|
| `1.1` / `1.16` | 主標（`--f-43` / `--f-24`） |
| `1.5` / `1.6` | 說明文字、卡片 hint、來源註記 |
| `1.65` / `1.7` | 正文段落、理由、切換條件、免責聲明 |
| `1.75` | 輸入頁介紹文案 |

### 1.4 字體家族

```css
font-family: Inter, "SF Pro Display", "PingFang HK", "PingFang TC", "Noto Sans TC", system-ui, sans-serif;
```

數字（時間、車費）使用 `font-variant-numeric: tabular-nums`。

## 2. 色彩

### 2.1 基礎

| Token | 值 | 用途 |
|---|---|---|
| `--canvas` | `#f4f6f6` | 頁面底色 |
| `--surface` | `#ffffff` | 卡片面 |
| `--line` | `#e3e8ea` | 邊框、分隔線 |

### 2.2 文字（4 檔，白色底對比度皆 ≥ 4.5:1）

| Token | 值 | 對比度 | 用途 |
|---|---|---|---|
| `--ink` | `#18222d` | 14.6:1 | 主要文字 |
| `--muted` | `#5a6672` | 5.9:1 | 次要文字、正文 |
| `--faint` | `#6b7683` | 4.6:1 | 標籤、說明、註記（最小字級仍達標） |
| `--deep` | `#263644` | — | 深色卡背景（切換條件） |

### 2.3 語意色（各含「文字色 + 淺底色」一對）

| 語意 | 文字色 | 淺底色 | 用途 |
|---|---|---|---|
| 主要 / 藍 | `--blue` `#2f6fe0`、`--blue-dark` `#245fc4` | `--blue-bg` `#eaf1fe` | accent、建議出發時間、連結、圖示 |
| 正常 / 綠 | `--green` `#0f6a46` | `--green-bg` `#e9f6f0` | 服務正常、低風險、系統狀態：正常 |
| 警示 / 琥珀 | `--amber` `#8f5a0e` | `--amber-bg` `#fff6e6` | 服務延誤、中風險、uncertain 橫幅、提醒 |
| 危險 / 紅 | `--red` `#a83232` | `--red-bg` `#fdeeee` | 服務中斷、高風險、已排除路線、錯誤 |
| 中性 chip | `--muted` | `#eef1f3` | 一般標籤、`服務狀態未確認` |

- 深色卡（切換條件）上：正文 `#eef3f7`、小標 `#9db3c6`、圖示 `#8fb6e8`、強調 `#ffffff`。
- **風險與信心一律「文字 + 圖示/量表」，不只靠顏色。**
- 服務狀態用色對應 `RouteStatus`：`ok`→綠、`delayed`→琥珀、`disrupted`→紅、`unknown`→中性。

## 3. 圓角（4 檔）

| Token | 值 | 用途 |
|---|---|---|
| `--r-sm` | `8px` | 欄位、按鈕、chip、統計格、徽章 |
| `--r-md` | `12px` | 次級區塊、提醒條、路線帶、深色卡內襯 |
| `--r-lg` | `16px` | 一般卡片 |
| `--r-xl` | `22px` | 主要卡片（決策摘要、狀態卡、輸入卡） |

膠囊型（`border-radius: 99px`）僅用於系統狀態徽章與品質標籤。

## 5. 間距

| 類別 | 值 |
|---|---|
| 卡片內距 | `20px`（一般）、`22px`（切換條件）、`32px`（輸入卡）、`28px 30px`（決策摘要桌面）、`18px 14px`（決策摘要行動）、`12px`（行動卡片） |
| 元素間距（gap） | `4 / 5 / 6 / 7 / 8 / 10 / 12 / 14 / 16 / 22 / 32 / 34 px`，最常用 `10px`、`12px`、`16px` |
| 頁面內距 | 結果頁 `20px 28px 8px`（桌面）／`10px 16px 8px`（行動）；輸入頁 `56px 28px 40px`／`26px 16px 32px` |
| 頁面最大寬 | 輸入頁 `1200px`、結果頁 `1260px`、頂欄 `1260px` |
| 頂欄高度 | `64px`（桌面）／`56px`（行動） |

## 6. 元件樣式

### 6.1 主要 CTA（`.primary-button`）

| 屬性 | 值 |
|---|---|
| 尺寸 | 滿寬 `52px` 高（`.compact` 版：`44px` 高、自動寬、內距 `0 18px`） |
| 底色 / 文字 | `--ink` `#18222d` / `#fff` |
| 圓角 | `--r-md` `12px` |
| 字 | `--f-15` / `700` |
| 陰影 | `--shadow-float` |
| hover | `#263441` + `translateY(-1px)` |
| **不使用 sticky / fixed**（避免遮擋欄位） |

### 6.2 次要按鈕（`.secondary-button`）

`44px` 高、`1px solid var(--line)`、白底、`--r-md`、`--f-13` / `600`。

### 6.3 卡片（`.card`）

`1px solid var(--line)`、白底、`--r-lg` `16px`、`--shadow-card`、內距 `20px`。
卡片標題列：`h3` `--f-17`；說明 `--f-13` `--faint`。

### 6.4 決策摘要（`.decision-card`）

桌面兩欄 `1.4fr : 0.8fr`（左：時間與到達；右：推薦路線與信心），`--r-xl` `22px`，中線 `1px --line`。
行動：單欄、右欄資訊接續在下方。

### 6.5 切換條件（`.switch-card`）

深色卡：底 `--deep` `#263644`、文字白、`--r-lg` `16px`、`--shadow-card`、內距 `22px`。
規則文字放在 `rgba(255,255,255,.08)` 的內襯塊（`--r-md`）。
`最遲切換決定：HH:mm` 以 `--f-17` 白字強調。

### 6.6 路線示意（`.route-strip`）

高度 `72px`（桌面）／`58px` → 行動 `52px`；淺底 `#f5f7f8`、`--r-md`。
左節點文字 → 粗線（顏色隨風險語意：藍／琥珀／紅／灰） → 右節點文字。
**不顯示距離、不畫虛構地理。**

### 6.7 時間軸（`.timeline`）

左側時間欄寬 `54px`（行動 `46px`），右側以 `2px --line` 作連接線；最後一段不顯示線。
每段：模式 chip（`--blue-bg` / `--blue-dark`）、線路名、指示、`from → to · 抵達 HH:mm`、可選備註（`--amber`）。

### 6.8 統計格（`.stat`）

底 `#f7f9f9`、`--r-sm`、內距 `10px 12px`；標籤 `--f-12` `--faint`、值 `--f-13`。
桌面 `auto-fit minmax(96px,1fr)`；行動固定 4 欄。

### 6.9 折疊控制（`.disclosure`）

`--r-sm`、`1px --line`、底 `#fbfcfc`、`--f-12` / `600`、`--faint`；
展開時 chevron 旋轉 90°（`prefers-reduced-motion` 時停用動畫）。

### 6.10 狀態色塊

| 元件 | 樣式 |
|---|---|
| 行動徽章 `.action-badge` | `--r-sm`、`--f-12` / `700`、內距 `7px 11px`；4 色：藍（depart_at）、紅（depart_now）、琥珀（wait）、中性（hold） |
| 狀態 chip `.chip` | 同上尺寸；綠／琥珀／紅／中性對應 `RouteStatus` |
| 風險頭 `.risk-head` | 38px 圖示塊（圓角 `--r-md`）+ 標題 `--f-15` + 副標 `--f-13` |
| 信心量表 `.confidence-scale` | 3 格，每格 `24×5px`、圓角 5px；亮格數 = high 3 / medium 2 / low 1 |
| 品質標籤 `.quality-chip` | 膠囊、`#eef1f3` / `--muted`、`--f-12` / `700` |

## 7. 圖示

- **來源**：專案內自繪 inline SVG（`Icon` 元件），無第三方圖示庫。
- **規格**：`viewBox="0 0 24 24"`、`fill="none"`、`stroke="currentColor"`、`stroke-width="1.8"`、圓頭圓角（`round`）。
- **尺寸**（實際使用）：`13 / 14 / 15 / 16 / 17 / 18 / 20 / 22 / 28 px`。
- **圖示集**：`arrow`、`clock`、`route`、`shield`、`alert`、`swap`、`pin`、`chevron`、`refresh`、`rain`、`train`、`bus`、`walk`、`block`、`info`。
- 一律 `aria-hidden="true"`，語意由相鄰文字承擔（**不只靠圖示或顏色傳達狀態**）。
- 交通模式對應：`mtr`→train、`bus`/`minibus`→bus、`walk`→walk、其餘→route。

---

## 8. 無障礙

- `:focus-visible` 統一 `3px` 外發光（`rgba(47,111,224,.25)`，offset 2px）。
- 支援 `prefers-reduced-motion: reduce`（關閉動畫與平滑捲動）。
- 文字對比度全數 ≥ 4.5:1（最小字級 `--f-12` 亦達標）。
- 行動目標：主要按鈕 `44px` 以上。
- 狀態不只靠顏色：風險／服務狀態／信心皆有文字或圖示。
