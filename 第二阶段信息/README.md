## 如何运行第一阶段的完整应用

```bash
cd 第一阶段_归档/02-完整测试包/01-app
npm install      # 依赖已装过，可跳过
npm run dev      # 打开 http://localhost:3000
```

环境要求：Node.js ≥ 20.11（本机 v24.21.0 已验证），**不需要数据库、不需要任何 API 密钥**。

常用命令：

| 命令 | 用途 |
|---|---|
| `npm run dev` | 开发服务器 http://localhost:3000 |
| `npm run verify` | `lint → typecheck → test → build` 一次跑完（推荐） |
| `npm run smoke` | 功能冻结验收：三情景各 5 次 |
| `npm run test` | 全部单元/集成测试（15 文件 / 172 测试） |

界面参考基线（静态版，无需安装）：

```bash
cd 第一阶段_归档/02-完整测试包/02-ui-reference/dist
python3 -m http.server 8080    # 打开 http://localhost:8080
```

## 进入第二阶段

第二阶段文件直接放本目录，建议这样起步：

```bash
cd ~/Desktop/八校黑客松
cp -R 第一阶段_归档/02-完整测试包/01-app ./app
cd app
npm install
npm run verify     # 先跑通：lint → typecheck → test → build，确认基线干净
```

- 用 `02-完整测试包/01-app`（完整版，15 测试文件 / 172 测试，含实时数据适配器）
- 不要用 `01-应用-成员A版/`（成员 A 的早期快照，缺实时适配器与 6 个测试文件）
- `第一阶段_归档/` 视为只读，改动只在根目录内进行

第二阶段完成后：新建 `第二阶段_归档/`，把根目录里的第二阶段文件（如 `app/`）移进去，保持根目录只有归档文件夹。
